# 讨论记录

本目录存放本项目的全部讨论过程与结论。**后续讨论内容一律存入此路径。**

## 项目一句话

为一家位于上海的**体外诊断（IVD / In Vitro Diagnostics，体外诊断）试剂贸易公司**，构建一套「外部政策情报 + 内部经营数据」联动的知识库 / 决策支持系统：先用自身经营判断，远期演进为可对外服务的产品。

## 待确认的开放问题

1. **上海 2026 省际联盟 IVD 集采的中选企业与中选价格清单**——发布在国家医保招采子系统内，需登录下载，公开网页无。这是整个分析的核心输入。
2. 该省际联盟的**牵头省份**是哪个（影响未来 2 年规则解读与续约走向）。
3. 公司主力品类是否集中在**糖代谢 / 生化**（决定两份政策的冲击强度）。
4. **ERP 是否存有旧医保编码字段**——若有，映射难度下降一个数量级。
5. ERP 可提供的字段清单（详见 04 文档末「需要从 ERP 提供的东西」）。
