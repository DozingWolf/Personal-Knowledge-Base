## 与讨论文档的对应关系

定稿文档不是另起炉灶，而是从讨论文档**收敛**而来：

```mermaid
flowchart LR
  D["discuss/01-07<br/>过程与推理"] -->|"结论稳定、可交付"| P["docs/01-07<br/>定稿产品文档"]
  P -->|"架构级取舍"| A["docs/decisions/<br/>ADR"]
  D -.->|"被否决的方案、当时的犹豫"| K["保留在 discuss/<br/>不进入定稿"]
```

- 表结构的具体来源是 [discuss/04](../discuss/04-数据工程-SKU与检测项目映射.md)（设计）与 [discuss/06](../discuss/06-功能模块设计.md)（模块边界）。
